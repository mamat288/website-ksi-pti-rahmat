# 👖 DENIMVERSE
### Premium Denim E-Commerce Website with AI Fit Finder

DENIMVERSE adalah website toko online celana denim premium
dengan tampilan modern dan fitur AI Fit Finder untuk rekomendasi ukuran.

## 🚀 Fitur Utama
- Landing page modern & responsive
- Katalog produk denim
- Product detail page
- 🤖 AI Fit Finder (simulasi)
- UI e-commerce premium
- GitHub Pages ready

## 🛠️ Teknologi
- HTML5
- Tailwind CSS
- Custom CSS
- JavaScript
- GitHub Pages
